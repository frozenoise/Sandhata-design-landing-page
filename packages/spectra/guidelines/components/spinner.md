# Spinner

Indeterminate loading indicator in brand blue.

## Props

| Prop | Type | Notes |
|---|---|---|
| `size` | number | Diameter in px |
| `stroke` | number | Stroke width |
| `color` | string | Override colour (defaults to brand blue) |

## Example

```jsx
import { Spinner } from "@sandhata/spectra";

<Spinner size={20} />
```
